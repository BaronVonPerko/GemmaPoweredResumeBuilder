# AI Behavior and Interaction Style

This file defines how the AI agent must behave during development.

## Core Behaviors

- **Thoroughness**: Always inspect the codebase using appropriate read tools before making edits. Trace symbols and understand the existing structure.
- **Proactive Verification**: Check for linter errors immediately after edits.
- **Code Refactoring**: When refactoring, follow existing conventions and preserve formatting. Do not perform speculative or unrequested modifications.
- **Self-Sufficiency**: Find answers within the repository or web searches instead of asking the user for help, unless genuinely blocked.
