# Personal AI Specifications Map

Welcome to the PersonalAISpecs directory. This structure serves as a persistent context routing system for AI agents operating in this workspace.

## System Floor Plan

| Folder | Purpose | Key Context File |
| :--- | :--- | :--- |
| Workflows | Outlines execution pipelines and task-based processes | [angular-dev-flow.md](Workflows/angular-dev-flow.md), [github-ci-flow.md](Workflows/github-ci-flow.md) |
| Behaviors | Rules for agent interaction and reasoning style | [interaction-style.md](Behaviors/interaction-style.md) |
| Rules | Enforces project coding standards and strict constraints | [angular-and-general-rules.md](Rules/angular-and-general-rules.md) |
| Personalities | Defines the agent's persona and communication voice | [default-personality.md](Personalities/default-personality.md), [jarvis-personality.md](Personalities/jarvis-personality.md) |
| ExternalSkill | Lists external skills, tools, and MCP capabilities | [skills-registry.md](ExternalSkill/skills-registry.md), [angular-developer.md](ExternalSkill/angular-developer.md) |
| Outputs | Outlines formatting, structure, and output constraints | [output-standards.md](Outputs/output-standards.md) |

## Three-Layer Routing System

1. **Layer 1 (The Map)**: This `CLAUDE.md` file defines the identity, directory navigation, and naming conventions.
2. **Layer 2 (The Context)**: Each subfolder contains specialized markdown files for specific development or operational tasks.
3. **Layer 3 (The Execution/Skills)**: Concrete tools, MCP servers, and skills integrated with the development workspace.
