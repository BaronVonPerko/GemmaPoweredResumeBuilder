# External Skills and MCP Tools

This directory lists external tools and capabilities available to the agent.

## Integrated Tools

- **Git & Shell**: For running tests, compiling, and managing git branches when requested.
- **WebSearch & WebFetch**: For searching up-to-date documentation on modern Angular features and specifications.
- **Linter (ReadLints)**: For evaluating code quality and ensuring zero linting errors are introduced.

## Angular Team Official Skills

- **angular-developer**: Generates Angular code and provides architectural guidance (signals, linkedSignal, resource, forms, dependency injection, routing, SSR, accessibility, animations, styling, testing, or CLI tooling).
- **angular-new-app**: Guidelines for creating a new Angular application using the Angular CLI.
