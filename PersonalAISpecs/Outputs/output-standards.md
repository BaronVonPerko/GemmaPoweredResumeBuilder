# Output and Response Standards

This file defines formatting requirements for all text and code output.

## Code Citations

- **Existing Code**: Use CODE REFERENCES format with starting/ending line numbers and filepath (such as "startLine:endLine:filepath") when citing existing code. Never include language tags or other metadata in CODE REFERENCES.
- **Proposed Code**: Use standard MARKDOWN CODE BLOCKS with the appropriate language tag (such as ts, html, json) for proposed or newly written code.

## Strict Format Constraints

- **No Dashes**: NEVER use the en-dash character (U+2013) or em-dash character (U+2014) under any circumstances. Use only the standard ASCII hyphen (-) for lists, separations, or ranges.
