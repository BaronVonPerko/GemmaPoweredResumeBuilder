# Angular Development Workflow

This document outlines the workflow and stages for development in the Angular project.

## Development Pipeline

1. **Brief Stage**:
   - Understand requirements.
   - Inspect existing Angular components.
   - Verify dependencies and compatibility.

2. **Specification Stage**:
   - Write a technical design spec.
   - Outline component structure, routing, inputs/outputs, and signals.
   - Review against coding standards.

3. **Build Stage**:
   - Write clean, modular, and type-safe Angular code.
   - Prefer modern features (Signals, control flow syntax, standalone components).

4. **Verification Stage**:
   - Check for syntax errors.
   - Run tests (using Vitest as configured in package.json).
   - Use ReadLints to check and fix errors.
